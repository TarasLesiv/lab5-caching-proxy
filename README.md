# Кешуючий проксі-сервер на Node.js (Лабораторна робота №5)

Найпростіший кешуючий HTTP-проксі-сервер на базі вбудованого модуля `node:http`, який отримує картинки кодів стану HTTP із сайту [https://http.cat](https://http.cat), зберігає їх у локальному кеші на диску та віддає клієнтові з кешу під час повторних запитів.

Увесь асинхронний код реалізовано виключно за допомогою промісів та `async/await` (`node:fs/promises`, `superagent`, асинхронний ітератор потоку `for await...of`).

## Встановлення та запуск

```bash
npm install
node main.js -h 127.0.0.1 -p 3000 -c ./cache
```

Також у `package.json` налаштовано готові сценарії:

```bash
npm start      # запуск на 127.0.0.1:3000 із текою кешу ./cache
npm run dev    # запуск через node --watch на 127.0.0.1:3005
```

## Параметри командного рядка

| Опція | Обов’язковість | Опис |
| :--- | :--- | :--- |
| `-h, --host <address>` | обов’язкова | адреса, на якій працює сервер |
| `-p, --port <number>` | обов’язкова | порт сервера (`1–65535`) |
| `-c, --cache <path>` | обов’язкова | шлях до теки для збереження кешованих картинок |
| `--help` | необов’язкова | показати довідку |

Якщо тека кешу не існує, сервер автоматично створює її під час запуску до початку приймання запитів.

## Підтримувані HTTP-методи

Маршрут задається трицифровим кодом стану HTTP у шляху URL (наприклад, `/200`, `/404`, `/418`):

| Метод | Дія сервера | Код відповіді |
| :--- | :--- | :--- |
| `GET /<code>` | Повертає картинку з кешу (`X-Image-Source: cache`) або завантажує її з `https://http.cat/<code>`, зберігає в кеш і віддає клієнту (`X-Image-Source: http.cat`) | `200 OK` (`image/jpeg`) або `404 Not Found` |
| `PUT /<code>` | Зберігає двійкове тіло запиту в кеш або замінює наявну картинку | `201 Created` (`400`, якщо тіло порожнє) |
| `DELETE /<code>` | Видаляє картинку для вказаного коду з кешу | `200 OK` або `404 Not Found` |
| Будь-який інший | Метод не підтримується (повертається заголовок `Allow: GET, PUT, DELETE`) | `405 Method Not Allowed` |
